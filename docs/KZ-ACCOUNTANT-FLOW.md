Справочник документов, которые MCP умеет создавать, менять и проводить (`write.document.create_document`,
`write.document.update_document`, `write.document.post_document`). Тот же справочник отдаёт инструмент
`read.system.kz_document_guide` и `read.system.capabilities` (`kazakhstanDocumentsUsage`).

## Отчёты: ОСВ, карточка счёта, сальдо

- **ОСВ / сальдо по счёту** — `read.accounting.get_account_turnover` (регистр «Типовой»): сальдо на начало, обороты Дт/Кт,
  сальдо на конец; `byAnalytics: true` — разбивка по субконто (сотрудник, контрагент, налог). Сверки после флоу: 1250 по
  подотчётному = 0 после авансового отчёта; 3350 = 0 после выплаты зарплаты; 3310/1210 по контрагенту — долг/аванс.
- **Карточка документа** — `read.accounting.get_document_postings`: все проводки документа, `post_document` возвращает их сразу.
- **Налоги**: НДС (ст. 503, 16%), ИПН/КПН (ст. 357, 403), упрощённая декларация 910 (ст. 726, 4%) — начисление по
  декларации делается документом «Отражение налоговой отчётности»; ставки и КБК — `read.system.kz_document_guide`.
- **ЭСФ** — отправка в ИС ЭСФ через OData невозможна (делается в 1С/ИС ЭСФ); MCP создаёт счёт-фактуру как основу
  и читает статусы `read.esf.list_esf`.

## Правила записи

- Всегда предпросмотр (`confirm=false`) → проверить `notes` → `confirm=true` с тем же `operationId` → `post_document` →
  проверить проводки и сальдо.
- 1С не заполняет счета учёта при создании через OData: передавайте `sampleRef` (проведённый документ того же вида
  или другого вида через `sampleEntitySet`) или коды счетов Типового плана (`"1330"`) — сервер заменит их ссылками
  (для НУ — счёт Налогового плана с суффиксом «Н»).
- Значения перечислений (`ВидОперации` и др.) в `$metadata` нет — сервер проверяет их по значениям, снятым с базы.
- Платёжное поручение и платёжные ордера проводятся только с `Оплачено=true` (и `ДатаВыписки`); статья ДДС не обязательна.
- Зарплата: сначала проверить начисления и ЕП за месяц. При ЕП (ст. 822) нет классических удержаний и СН/СО; Дт расходов
  Кт 3350; удержания Дт 3350 Кт 3120/3220/3212 (ЕП — 3231); взносы работодателя Кт 3211/3250/3213 (ЕП — 3231);
  после выплаты сальдо 3350 = 0. Базовый вычет 30 МРП — только по заявлению работника.
- Закрытие месяца — только с согласия бухгалтера (последний день месяца, перепроводит себестоимость и финрезультат).
- Обходы 1С (прямая запись `Posted`, проводки в обход документа) запрещены.
