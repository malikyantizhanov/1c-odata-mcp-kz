# Расширение «MCP: печатные формы во вложения»

Для 1С:Бухгалтерии для Казахстана, ред. 3.0 (в том числе в 1С:Fresh).

Печатные формы 1С формирует своим кодом в момент печати — через OData их не вызвать. Это расширение
после записи документа само формирует его стандартную печатную форму (ту же, что команда «Печать»),
сохраняет в PDF и прикрепляет к документу с описанием **«Печатная форма 1С (MCP)»**. Одно расширение
на все документы; сейчас включён **счёт на оплату покупателю**, другие добавляются в том же расширении.
MCP забирает файл через OData (`read.files.list_attachments` → `read.files.get_attachment`) и отдаёт агенту,
поэтому клиент получает настоящий счёт из 1С.

Расширение не добавляет объектов и не меняет структуру данных — только общий модуль и подписку на событие,
поэтому подходит для безопасного режима 1С:Fresh.

## Сборка (конфигуратор)

1. Откройте копию базы (для 1С:Fresh — копия приложения для локальной работы или демо-база той же редакции).
2. «Конфигурация → Расширения конфигурации → Добавить». Имя: `МСП_ПечатьВоВложения`, синоним:
   «MCP: печатные формы во вложения», назначение: «Адаптация». Безопасный режим — да.
3. Заимствуйте в расширение документ `СчетНаОплатуПокупателю` (правый щелчок в дереве основной
   конфигурации → «Добавить в расширение»; свойства не меняйте).
4. Создайте общий модуль `МСП_ПечатьВоВложения`: «Сервер» — да, «Клиент», «Вызов сервера»,
   «Привилегированный» — нет. Вставьте код из `МСП_ПечатьВоВложения.bsl`.
5. Создайте подписку на событие `МСП_ПечатьВоВложения`:
   источник — `ДокументОбъект.СчетНаОплатуПокупателю`, событие — `ПриЗаписи`,
   обработчик — `МСП_ПечатьВоВложения.ДокументПриЗаписи`.
6. Сверьте места с пометкой «ПРОВЕРИТЬ» в модуле:
   - идентификатор макета в функции `ИдентификаторМакета` — в модуле менеджера документа
     `СчетНаОплатуПокупателю`, процедура `ДобавитьКомандыПечати`, поле «Идентификатор» команды печати счёта
     (в БК для Казахстана 3.0 — `СчетЗаказНаОплату`, уже прописан);
   - сигнатуру процедуры `Печать` в модуле менеджера (стандарт БСП);
   - API присоединённых файлов (`РаботаСФайлами.ПараметрыДобавленияФайла` / `ДобавитьФайл` — БСП 3.x).
7. «Конфигурация → Сохранить расширение в файл» — получится `МСП_ПечатьВоВложения.cfe`.

## Проверка на копии базы

1. Создайте или перезапишите счёт на оплату.
2. Через несколько секунд у счёта во «Присоединённых файлах» должен появиться
   `Счет на оплату покупателю № N от ДД.ММ.ГГГГ.pdf` с описанием «Печатная форма 1С (MCP)» — откройте и сравните
   с печатью по кнопке. Ошибки — в журнале регистрации, событие «MCP.ПечатьВоВложения».
3. Повторная запись счёта заменяет файл: прежний помечается на удаление.

## Как добавить другой документ

Новое расширение не нужно — в этом же:

1. Возьмите документ в расширение («Добавить в расширение»).
2. В подписке `МСП_ПечатьВоВложения` отметьте его объект в «Источнике» (напр. `ДокументОбъект.РеализацияТоваровУслуг`).
3. В функции `ИдентификаторМакета` добавьте ветку с именем документа и идентификатором его команды печати
   (модуль менеджера документа → `ДобавитьКомандыПечати`). Для реализации и счёта-фактуры в коде есть заготовки.
4. Пересоберите `.cfe` и обновите расширение в базе.

Справочник файлов (`<ИмяДокумента>ПрисоединенныеФайлы`) модуль находит сам; он должен быть в составе OData,
чтобы MCP мог забрать PDF.

## Установка в 1С:Fresh

«Администрирование → Печатные формы, отчёты и обработки → Расширения → Добавить из файла» и выбрать
`.cfe`. После установки перезапустите приложение. Справочник `СчетНаОплатуПокупателюПрисоединенныеФайлы`
должен быть в составе стандартного интерфейса OData (в 1С:Fresh.kz он опубликован по умолчанию).

## Если фоновые задания недоступны

Если в безопасном режиме 1С:Fresh расширению нельзя запускать фоновые задания, в обработчике
`СчетНаОплатуПриЗаписи` вместо `ФоновыеЗадания.Выполнить(...)` вызовите `ПрикрепитьПечатнуюФорму(Источник.Ссылка)`
напрямую и уберите ожидание `ДождатьсяЗаписи` (документ виден внутри своей транзакции). Минус: печать идёт
в транзакции записи — при ошибке записи файла запись счёта тоже будет отменена.
